# Выгрузки ДУП SimBase

Каждый текстовый массив из папки «ДУП SimBase» разобран в отдельный Excel: договоры, заявки на закупку, заявки на оплату и служебные записки, отдельно авторы и согласующие.

Записи разделены точкой с запятой только тогда, когда сразу после неё начинается номер следующей записи. Точка с запятой внутри темы остаётся в теме.

У согласующих колонки: номер, наименование процесса, тема, компания, филиал, дата создания, инициатор, бухгалтер, должность.

У авторов бухгалтера в массиве нет. Восьмое поле — должность инициатора, девятое — числовой код без кавычек. Эти два столбца названы «Должность» и «Код».
