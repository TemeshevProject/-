# Выгрузки SimBase

Каждый исходный текстовый массив разобран в отдельный Excel. Колонки во всех файлах одинаковые: номер, наименование процесса, тема, компания, филиал, дата создания, инициатор, бухгалтер, должность.

Записи разделены точкой с запятой только тогда, когда сразу после неё начинается номер следующей записи. Точка с запятой внутри темы остаётся в теме.

Пустые компания, филиал и дата оставлены пустыми. Дата записана как дата Excel в формате дд.мм.гггг.
